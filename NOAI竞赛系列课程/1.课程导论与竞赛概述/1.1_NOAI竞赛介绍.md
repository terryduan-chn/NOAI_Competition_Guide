## 一、NOAI竞赛背景与目标

### 1.1 什么是NOAI

**NOAI**（National Olympiad in Artificial Intelligence，全国人工智能奥林匹克竞赛）是面向高中生的权威人工智能学术竞赛。该竞赛借鉴了国际信息学奥林匹克竞赛（IOI）等传统学科竞赛的组织模式，将人工智能确立为一门独立的竞赛学科，致力于在基础教育阶段推动AI学术教育的发展。

NOAI的定位非常明确：**聚焦于科学共同体认可的人工智能学科边界之内**的概念，以**机器学习和深度学习**为主要考察领域，以**数据驱动**为主要特征。NOAI不属于"泛人工智能"范畴，不涉及开源硬件、教育机器人、图形化编程等泛科技教育领域。这意味着选手需要具备扎实的数学基础、编程能力和对AI核心理论的深入理解，而非停留在工具使用和科普层面。

### 1.2 竞赛目标

NOAI竞赛的核心目标包括：

- **知识考察**：系统评估选手对人工智能基本概念、核心算法、关键技术的理解深度
- **能力培养**：培养选手运用计算思维解决AI相关问题的能力，包括数据处理、模型构建、实验分析等
- **素养提升**：引导选手关注AI伦理、社会责任和技术发展的辩证关系
- **人才选拔**：为国家级AI人才储备提供标准化评估通道

### 1.3 选手基本要求

除AI专业知识外，NOAI要求选手具备《普通高中课程方案》规定的全部核心素养和基本能力。其中对于**数学、物理、化学、生物、信息技术**学科，需达到对应学科课程标准中"希望大学选择人工智能相关专业"方向的必修与选修内容及能力要求。这意味着选手不仅需要会编程，还需要具备良好的数学推理能力和科学思维能力。

## 二、竞赛结构

NOAI竞赛采用**两轮制**，每轮考查不同的知识区域，形成从基础到进阶的递进式考核体系：

```
NOAI竞赛结构
├── 第一轮：水平测试轮（闭卷笔试）
│   ├── A区：一般计算机技能
│   └── B区：人工智能基础知识
└── 第二轮：应用实践轮（上机实践）
    ├── C区：进阶计算机技能
    └── D区：人工智能进阶知识与技能
```

### 2.1 第一轮：水平测试轮

- **形式**：闭卷笔试
- **考查区域**：A区 + B区
- **定位**：基础水平测试，考查选手通过预先学习所掌握的基本概念和方法
- **核心要求**：选手需在无外部资料辅助的条件下，准确回答涉及AI理论和Python编程基础的问题
- **通过标准**：达到规定分数线方可进入第二轮

### 2.2 第二轮：应用实践轮

- **形式**：上机实践（可查阅文档）
- **考查区域**：C区 + D区
- **定位**：应用能力评估，考查选手在实际操作环境中解决AI问题的综合能力
- **核心要求**：选手需使用Python及相关AI工具库（如NumPy、Pandas、PyTorch等）完成数据处理、模型训练、结果分析等实际任务
- **重要说明**：第二轮允许选手在竞赛过程中查阅官方文档和API手册，重点考查的是**在文档帮助下快速学习和应用新工具的能力**，而非死记硬背API

## 三、A/B/C/D四大考核区域详解

### 3.1 A区：一般计算机技能（第一轮）

A区是NOAI竞赛的基础支撑，主要考查选手的Python编程基本功。NOAI选择Python作为竞赛语言，因其是当前AI领域最主流的编程语言，拥有最丰富的工具生态。

**A区核心考核内容：**

| 子领域 | 具体内容 | 重要程度 |
|--------|----------|----------|
| 基本语法 | 变量、数据类型（int/float/bool/str）、运算符、输入输出 | ★★★★★ |
| 控制结构 | if/elif/else分支、for/while循环、break/continue | ★★★★★ |
| 数据结构 | 字符串、列表、字典、元组的操作与方法 | ★★★★★ |
| 函数与模块 | def定义函数、参数传递、返回值、lambda、标准库使用 | ★★★★☆ |
| 算法基础 | 排序算法（冒泡/选择/插入）、查找算法（线性/二分） | ★★★★☆ |
| 代码阅读 | 能读懂和分析给定Python代码的功能和输出 | ★★★★☆ |

**备考要点**：A区看似简单，但考查的深度不容小觑。选手不仅要会写代码，还需要能**阅读理解**他人代码、**分析调试**错误代码、**优化改进**给定代码。

### 3.2 B区：人工智能基础知识（第一轮）

B区是第一轮笔试的核心部分，也是NOAI竞赛知识体系的主干。B区涵盖从机器学习基础理论到深度学习核心概念的完整知识链。

**B区核心考核内容：**

| 子领域 | 具体内容 | 重要程度 |
|--------|----------|----------|
| 方法范式 | 监督学习、无监督学习、强化学习的区别与应用场景 | ★★★★★ |
| 经典算法 | 线性回归、逻辑回归、K-NN、决策树、SVM、朴素贝叶斯 | ★★★★★ |
| 集成学习 | Bagging、随机森林、梯度提升（XGBoost） | ★★★★☆ |
| 模型评估 | 混淆矩阵、精确率、召回率、F1、ROC/AUC、交叉验证 | ★★★★★ |
| 过拟合与正则化 | 偏差-方差权衡、L1/L2正则化、Dropout | ★★★★★ |
| 神经网络 | 感知机、MLP、前向传播、反向传播、激活函数 | ★★★★★ |
| CNN | 卷积层、池化层、全连接层、局部感受野、权重共享 | ★★★★☆ |
| 数学基础 | 概率论（贝叶斯）、统计学（均值/方差/相关系数）、距离度量 | ★★★★☆ |
| 大语言模型 | Transformer架构概述、预训练-微调范式、LLM基本概念 | ★★★☆☆ |

**考查层次说明**：NOAI大纲中使用三个层次描述知识要求：
- **知道（Know）**：了解概念的定义和基本含义
- **理解（Understand）**：能解释概念的原理、过程和逻辑
- **掌握（Master）**：能运用知识分析和解决新问题

### 3.3 C区：进阶计算机技能（第二轮）

C区是在A区基础上的能力升级，重点考查选手使用专业数据科学工具进行**数据处理和可视化**的能力。

**C区核心考核内容：**

| 工具/领域 | 具体内容 | 重要程度 |
|-----------|----------|----------|
| NumPy | 数组创建与运算、广播机制、统计函数、形状变换 | ★★★★★ |
| Pandas | DataFrame操作、数据读取/查询/过滤、缺失值处理、数据融合 | ★★★★★ |
| Matplotlib | 基础图表（折线/柱状/散点/直方图）、图表自定义 | ★★★★☆ |
| 特征工程 | 滑动窗口、池化操作、One-hot编码、统计矩特征 | ★★★★☆ |

**考查方式**：C区主要通过第二轮上机实践题考查。选手需要根据题目要求，使用上述工具完成数据加载、清洗、特征提取和可视化等任务。

### 3.4 D区：人工智能进阶知识与技能（第二轮）

D区是NOAI竞赛的最高层次考查区域，要求选手能够**使用深度学习框架解决实际的AI问题**。

**D区核心考核内容：**

| 子领域 | 具体内容 | 重要程度 |
|--------|----------|----------|
| PyTorch基础 | 张量操作、自动微分（Autograd）、nn.Module | ★★★★★ |
| 训练流程 | 数据加载→模型定义→损失函数→优化器→训练循环→评估 | ★★★★★ |
| 计算机视觉 | CNN图像分类、图像处理基础、迁移学习 | ★★★★☆ |
| 自然语言处理 | 文本预处理、词嵌入、文本分类、Transformer | ★★★★☆ |
| 语音处理 | MFCC特征、语谱图、ASR/TTS基本概念 | ★★★☆☆ |
| 大语言模型 | LLM API调用、本地部署、Prompt工程 | ★★★☆☆ |
| GPU训练 | 设备选择、数据迁移、混合精度训练概念 | ★★★☆☆ |

## 四、评分标准与题型分析

### 4.1 第一轮题型分析

第一轮为闭卷笔试，主要题型包括：

| 题型 | 说明 | 示例 |
|------|------|------|
| **选择题** | 考查概念辨析和基本理解 | "以下哪个不属于监督学习？" |
| **填空题** | 考查关键术语和数值计算 | "ReLU函数在x>0时的输出为____" |
| **简答题** | 考查对原理的理解和表达能力 | "请解释过拟合产生的原因" |
| **代码阅读题** | 给出Python代码，分析其功能或输出 | "以下代码的输出是什么？请解释原因" |
| **代码填空题** | 给出不完整代码，填写关键部分 | 补全梯度下降的核心计算步骤 |
| **计算题** | 考查手动计算能力 | "给定混淆矩阵，计算精确率和召回率" |

### 4.2 第二轮题型分析

第二轮为上机实践，题型更加综合和开放：

| 题型 | 说明 | 能力考查 |
|------|------|----------|
| **数据处理题** | 使用NumPy/Pandas完成数据清洗 | 数据操作能力 |
| **可视化题** | 使用Matplotlib生成指定图表 | 数据表达能力 |
| **模型构建题** | 使用PyTorch搭建指定结构的神经网络 | 框架使用能力 |
| **实验分析题** | 运行给定实验代码，分析结果并回答问题 | 实验分析能力 |
| **综合项目题** | 从数据到模型的完整项目流程 | 综合应用能力 |

### 4.3 评分原则

NOAI的评分遵循以下原则：

1. **理解优先**：重点评估选手对概念的理解深度，而非机械记忆
2. **过程与结果并重**：对于计算题和编程题，不仅看最终结果，也看解题过程
3. **第一轮门槛制**：第一轮为资格赛，达到分数线即可晋级，不排名
4. **第二轮积分制**：第二轮按总分排名，决定最终获奖等级

## 五、NOAI与国际AI竞赛的关系

### 5.1 IOAI（International Olympiad in Artificial Intelligence）

IOAI是国际人工智能奥林匹克竞赛，NOAI与之在学术目标和考核理念上保持一致。IOAI的考核框架同样分为理论基础和应用实践两部分，涵盖机器学习、深度学习、计算机视觉、自然语言处理等核心领域。

**NOAI与IOAI的关系：**
- NOAI是中国选手参加IOAI的重要准备平台
- NOAI学术大纲参考了IOAI Syllabus的框架结构
- NOAI的考核难度和深度与IOAI保持对齐
- 通过NOAI选拔的优秀选手有机会代表中国参加IOAI

### 5.2 IAIO Training Guide

IAIO（International AI Olympiad）Training Guide是由国际AI竞赛教练Eljakim Schrijvers编写的权威训练教材，是NOAI备考的重要参考资源。该书系统涵盖了AI竞赛所需的全部理论知识，并配有大量练习题和解析。

### 5.3 竞赛生态定位

```
竞赛生态定位图

IOAI（国际级）
  └── NOAI（国家级） ← 本课程对标
        ├── 省级选拔赛
        └── 校级/兴趣小组
```

NOAI作为国家级竞赛，在竞赛生态中承担着**承上启下**的关键角色：向上衔接IOAI等国际赛事，向下引领省级选拔和学校AI教育。
